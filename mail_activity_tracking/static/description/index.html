Feature Details

1. Post Message in Chatter

Open any document (Sale Order, Invoice, Lead, Ticket, etc.) that supports chatter functionality and post a message to notify recipients.

2. Select Email Recipients

Select the recipients who should receive the email notification from the chatter message.

3. Send Chatter Message

Send the message and allow Odoo to generate email notifications for the selected recipients.

4. View Notification Tracking

View the notification tracking information directly within the chatter message.

5. Recipient Status Icons

Each notified recipient is displayed with an intuitive status icon indicating the current email status.

6. Monitor Delivery Status

Quickly monitor whether notifications were sent successfully, delivered, opened, or encountered delivery issues.

Frequently Asked Questions

Common questions about email activity tracking, compatibility, and settings

Is This App Compatible With Odoo Community & Enterprise?
Yes. This module works perfectly with Odoo 17 Community Edition, Enterprise Edition, and Odoo.sh deployments.
What Does Mail Activity Tracking Do?
This module displays email notification tracking information directly in Odoo chatter, helping users monitor notification delivery and recipient status in real time.
Where Can I View Email Notification Statuses?
Notification statuses are displayed directly within the chatter alongside the recipients of each message.
What Types Of Statuses Can Be Tracked?
The module helps users identify notification delivery statuses such as sent, delivered, opened, and other tracking states supported by Odoo mail servers.
Does This Module Require Additional Configuration?
No. After installation, the tracking information becomes available directly within Odoo chatter automatically without extra manual setup.
